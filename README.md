# Honey House — Natural Honey Store

เว็บไซต์ร้านน้ำผึ้งตัวอย่าง พร้อมระบบตะกร้าสินค้า หน้าจัดการออเดอร์ และ Google Apps Script สำหรับเชื่อม Google Sheets

## สินค้าตัวอย่าง
- HH-001 น้ำผึ้งดอกลำไย 250 กรัม — 159 บาท
- HH-002 น้ำผึ้งป่า 500 กรัม — 279 บาท

## การตั้งค่า
ดูขั้นตอนเชื่อม Google Sheets และ deploy บน Vercel ใน README ฉบับเต็มของโปรเจกต์
